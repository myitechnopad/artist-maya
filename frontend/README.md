# 🎭 Portfolio Frontend (React + Vite + TypeScript)

This is a modern **frontend web application** built using **React, TypeScript, and Vite**.  
It showcases sections like About, Theatre, Film & TV, Film Production, Art Works, Gallery, and Contact.

---

## 🚀 Tech Stack

- ⚛️ React (TypeScript)
- ⚡ Vite
- 🎨 Tailwind CSS
- 🎯 React Icons
- 💡 Custom Components
